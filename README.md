# Injektoren-Ausbau-Mobile.de

Deutsche Website für den mobilen Ausbau festsitzender Injektoren und Glühkerzen von Renovoservis.

## Seiten
- index.html – Startseite
- services.html – Leistungen
- about.html – Über uns
- contact.html – Kontakt

## GitHub Pages aktivieren
1. Gehe zu Settings > Pages
2. Source: Deploy from a branch → main / / (root)
3. Custom domain: injektoren-ausbau-mobile.de (CNAME ist bereits gesetzt)

## DNS
Für die Domain injektoren-ausbau-mobile.de:
- CNAME www → vytahovanivstrikurenovo-afk.github.io
- Oder A records für Apex auf GitHub Pages IPs (siehe GitHub Docs)

Inhalt basiert auf dem Spezialservice: Ausbau ohne Kopfdemontage, mobil in DE/CZ.

Bitte Kontaktdaten (Telefon, WhatsApp) in contact.html ergänzen.
